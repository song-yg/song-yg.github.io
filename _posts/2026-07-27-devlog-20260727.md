## 디버깅

위에서 말했듯 그런걸 했다.

<br>

열심히 죽여보기...

죽나 안죽나 지켜보기...

죽으면 살려내기...

<br>

테스트 해본 경우는 이정도.

* api 키 오류 ( . 입력)
* gdelt 키워드 갯수 5개 미만 (5개씩 끊어서 호출해서)
* 존재하지 않는 LLM 모델 입력
* csv 파일 내에 동일 키워드
* kor/eng 반대 입력
* 키워드 내 특수문자 입력
* 키워드 공백 (띄어쓰기 등)
* 만료된 api 키
* csv 링크 오류 (파일 변경 등)
